# 词源划词 WordRoot — Chrome Web Store 上架文案

> 短描述（manifest.json，限制 132 字符）已用：
> "划词即出词根词缀拆解与联想记忆的英语词典扩展，网页 / PDF / EPUB 全支持"

## 详细描述（商店展示用）

## 不止给中文释义 — 给你"为什么这么记"

大多数英语学习者卡在同一个点：

```
文章读不懂 → 因为单词不认识
单词记不住 → 因为只是随机字母
随机字母 → 因为不认识词根词缀
```

认识词根词缀之后，每个单词都会变成一个可拆解的"画面"：

```
inspect · or
  in-    →  向内
  spect  →  看
  -or    →  表示"人"
  整体含义：向内看的人 → 检查员
```

`respect / prospect / retrospect / spectator / spectacle` —— 一个 `spect`（看）就能串起一整串词。掌握约 200 个高频词根词缀，你能推导出数千个单词的含义。

但手动查词源的成本太高，**阅读节奏被打断 3 次后大多数人就会放弃**。所以做了这个扩展：把"查词根"压到零成本。

## 核心功能

### 1. 划词即查 — 不打断阅读流
选中任意英文单词，词源面板立刻弹出。覆盖：
- 任意网页（content script 注入）
- PDF 文件（自动接管 `.pdf` 链接到内置阅读器）
- EPUB 电子书（内置 epub.js 阅读器）
- 弹窗快捷查词

### 2. 三级词源 — 从快到深层层兜底
- **离线高频词库**：COCA 前 3000 词 × 有道释义（**毫秒级、断网可用**）
- **有道在线兜底**：释义 / 词源 / 同根词 / 例句（免费，无需 Key）
- **LLM 词源故事**：结构化词根拆解 + 联想记忆（用户自带 OpenAI 兼容 Key）

不配 Key 也能用，配 Key 后解锁深度。

### 3. 联想记忆 — 替代机械重复
把词根串成可脑补的画面或故事，而不是让你"再背一遍"。

### 4. 朗读发音 — 三档可选
- 有道在线发音（默认，免服务器免 Key）
- 本机系统语音
- 自建 edge-tts 中继（高级选项）

### 5. 内置 PDF / EPUB 阅读器
浏览器自带的 PDF 视图是受保护框架，扩展无法注入。WordRoot 内置 pdf.js 阅读器接管 PDF 链接，**PDF 里也能像网页一样划词查源**。

### 6. 生词本 — 查过的不白查
一键收藏查过的词（含完整词源快照）；支持搜索、朗读、**导出 Anki 制表符格式**（导入 Anki 时选"字段分隔符 = Tab"即可做成背词卡）。

### 7. 不上传任何数据
- 全部数据存在本机 `chrome.storage.local`
- 不收集任何用户身份信息
- 无分析、无遥测、无第三方 SDK
- 详细说明见项目内 PRIVACY.md

## 常见问题

**Q: 不配 API Key 能用吗？**
A: 完全可用。离线词库 + 有道在线兜底已经能覆盖日常阅读。API Key 是为了解锁"为什么这么记"的联想记忆。

**Q: 我的 API Key 安全吗？**
A: Key 只存在本机 `chrome.storage.local`，请求时直接发给你的 baseURL（默认 OpenAI 官方），不经任何中间服务器。

**Q: PDF 划词为什么默认开着？**
A: 浏览器自带 PDF 视图是受保护框架，扩展无法注入。这是核心功能不是附加项。如不需要可在选项页关闭。

**Q: 会收集我的浏览数据吗？**
A: 不会。详细见 PRIVACY.md。
