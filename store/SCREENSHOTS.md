# 截图操作指引（逐步照做）

商店截图要求：**宽 1280×高 800**（最小 640×400，推荐用 1280×800）。
一共建议 5 张，覆盖 5 个核心场景。每张都给了「前置 → 打开 → 操作 → 截图要点」。

> 通用准备（每张都要先做完）：
> 1. 打开 `chrome://extensions` → 右上角开「开发者模式」→「加载已解压的扩展程序」→ 选 `wordroot/` 目录。
> 2. 把 Chrome 窗口拉到 **1280×800**（Win：拖动窗口到差不多大，或用 `Win+Shift+S` 前先在设置里把显示缩放设 100%）。商店截图带浏览器边框也 OK，但内容区要尽量铺满。
> 3. 截图工具：推荐 `Win + Shift + S` 框选，或 F12 → 设备工具栏设 1280×800 → 右上「⋯」→ Capture screenshot。保存为 PNG。

## 截图 1（最重要）｜网页划词浮动面板 · 词根词缀拆解

**这是核心卖点，必须让面板里出现「词根词缀拆解 / 词源故事 / 联想记忆」。**

- **前置**：不用设 LLM Key。离线词库里 `reject / object / project / inject / subject / eject / adjective / traverse` 这 8 个词**自带拆解**，直接能出。
- **打开**：新标签页打开英文网页，例如 `https://en.wikipedia.org/wiki/Rejection`（里面到处是 "reject"，且页面干净适合截图）。
- **操作**：
  1. 鼠标双击选中页面里的单词 **reject**（或手动拖蓝选中这一个词）。
  2. 松开鼠标约 0.3 秒，右上浮出「词源划词」面板，显示：
     - 单词 + 英/美音标
     - **词根词缀拆解**：`re- (back, 回) + ject (扔/抛)`
     - **词源故事** + **联想记忆**（对比 eject / inject）
     - 底部「来源：离线词库」
  3. 若面板位置不理想（压住正文），点面板里「钉住」按钮固定，或重新选一个靠页面中部的 "reject"。
- **截图要点**：截**整个浏览器窗口**，让 Wikipedia 正文 + 浮层面板同框 —— 一眼看出"在任意网页划词即用"。
- 备选：若想截工具栏弹窗版，点扩展图标 → 在「输入英文单词」框打 `reject` 回车，也能看到同样的拆解（但网页浮动版更有说服力，优先用网页版）。

## 截图 2｜PDF 阅读器内划词

- **前置**：准备一份英文 PDF（任意，如论文/教材前几页；放桌面即可）。
- **打开**：
  1. 点扩展图标 → 弹窗里点「📄 打开本地 PDF」→ 跳到阅读器页 `reader.html`。
  2. 在阅读器里点左上「📂 打开 PDF / EPUB」→ 选你的英文 PDF。等待渲染（默认 130% 缩放）。
- **操作**：
  1. 在 PDF 正文里双击选中一个英文单词（如 "methodology" 或 "analysis"）。
  2. 浮层面板出现，显示该词释义（PDF 里划词体验和网页一致）。
- **截图要点**：截阅读器全貌 —— 顶部深灰工具栏（页码 / 缩放）+ 白色 PDF 页面 + 浮层。最好在面板里选一个有拆解的词（如果 PDF 里恰好有 ject 词族，面板会直接出拆解；没有也不影响，截"PDF 也能划词"即可）。

## 截图 3｜EPUB 阅读器内划词

- **前置**：准备一本英文 epub（无版权限制的可去 Project Gutenberg 下载，如《Pride and Prejudice》）。
- **打开**：
  1. 在阅读器页 `reader.html` 点「📂 打开 PDF / EPUB」→ 选 .epub 文件。
  2. 进入阅读视图（米色背景，工具栏变「上章 / 下章 / A- / A+」）。
- **操作**：在正文里选中一个单词 → 浮层出现，划词体验与网页一致。
- **截图要点**：截阅读视图全貌 —— 米色书页 + 浮层。证明"读原版书也能随时查词根"。

## 截图 4｜选项页（设置 LLM Key / 朗读 / PDF 接管）

- **打开**：`chrome://extensions` → 词源划词 → 详情 →「扩展选项」；或扩展图标右键「选项」。
- **操作**：
  1. 在「AI 词源（LLM）」区填好 `API Key` / `Base URL` / `Model`（这样截图里设置面板是"已配置"状态，显得完整）。
  2. **务必打码**：截图前把 API Key 输入框里的真实 Key **遮掉或删成 `sk-••••••••`** 再截（可用系统画图工具涂黑，或临时清空该框截）。
  3. 下方「朗读发音」「PDF 划词自动接管」开关保持默认（自动接管默认开，正是卖点）。
- **截图要点**：截整个选项页（从上到下）。**注意**：底部「使用统计」面板默认隐藏（开发者模式才显示），普通用户看不到 —— 截图时它不显示是正常的，不用管。

## 截图 5｜生词本

- **前置**：先在网页或 PDF 里划词 → 点面板「加入生词本」存 3–5 个词（建议存带拆解的词，如 reject / object / project，卡片更丰满）。
- **打开**：扩展图标 → 弹窗点「📚 生词本」→ 打开 `vocab.html`。
- **操作**：无需额外操作，页面已列出卡片（单词 + 音标 + 词根拆解 + 联想记忆 + 例句）。
- **截图要点**：截生词本列表（卡片网格）。可顺手点一张卡片展开看详情再截，或截列表即可。证明"查过的词一键收藏、带词源"。
